This is an informational landing page. It has no Connect button, does not receive authorization codes or tokens, and does not show live connection status.

The owner authorizes a company on Intuit's own Connect screen and completes setup in the local command-line tool. The tool requests the Accounting scope. To check which company is connected, run the local tool's status and company commands.

Never paste a QuickBooks authorization code, access token, refresh token, or financial data into this page or a public support issue.
